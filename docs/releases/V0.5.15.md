# DevSpace Ultra v0.5.15 — updater stage output contract

This maintenance release includes the complete v0.5.14 multi-computer MCP isolation and v0.5.13 live-safe update convergence.

The transactional updater now captures stdout/stderr from the staged `better-sqlite3` rebuild and in-memory native smoke test instead of allowing successful native-command text to enter the PowerShell function output pipeline. `Invoke-StagePackage` therefore always returns exactly one package object with `Prefix`, `Root` and `Manifest`, and the production update path no longer fails after a successful native rebuild with a missing `Root` or `Prefix` property.

The fix was accepted by a real 0.5.12 → 0.5.14 side-by-side update on Windows: the canonical package, native binding, Gateway/Core, public HTTPS, Caddy and all existing Main process IDs remained valid.
