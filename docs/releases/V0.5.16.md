# DevSpace Ultra v0.5.16 — token-bound Connector App origin discovery

This release completes the generic multi-computer isolation introduced in v0.5.14 while remaining compatible with ChatGPT sessions that cached older tool metadata.

The local progress relay resource now contains a random, in-memory, per-Core origin-probe URL. When ChatGPT renders that resource, its sandbox sends one credential-free CORS request back to the same DevSpace public origin. The server accepts the origin only when both the unguessable probe token and the strict OpenAI `asdk_app_*.web-sandbox.oaiusercontent.com` origin validate, then persists it under this installation's `serverInstanceId + public resource origin` boundary.

This lets the overlay identify and reclaim only this Connector's stale progress/Goal relay frames even when an old ChatGPT tool schema still mounts the relay on ordinary reports. A different DevSpace server or computer does not possess the probe token and cannot register its App identity, donate authority or have its frames counted toward this installation's cleanup limits.

The release includes all v0.5.15 updater fixes, v0.5.14 exact local invocation enforcement, v0.5.13 live-safe package migration and bounded per-conversation progress retention.
