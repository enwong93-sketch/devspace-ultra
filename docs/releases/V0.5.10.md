# DevSpace Ultra v0.5.10 — mandatory ChatGPT Classic MCP acceptance

This release makes the product contract explicit: DevSpace Ultra is primarily an OAuth-protected local development environment for **ChatGPT Classic on Windows**. Codex can execute installation and repair tasks, and optional Codex interoperability remains available, but a working Codex connection is not product acceptance.

The public installation framework now has one non-skippable order:

1. preserve existing state and prove local/public prerequisites;
2. create one ChatGPT Classic MCP connection for the exact stable `/mcp` URL;
3. complete OAuth, including a protected-tool trigger when authorization is deferred;
4. scan or refresh the authenticated catalogue and verify `read`, `write`, `edit`, `apply_patch`, `exec_command`, `write_stdin`, and `devspace_progress_report`;
5. enable the connection in a fresh ChatGPT Classic conversation;
6. run a real read plus an explicitly authorized disposable write/edit/command and read-back;
7. reconnect or open another fresh Classic conversation and prove authenticated access persists;
8. report every gate as pass/fail.

When an endpoint already passes external HTTPS/OAuth checks, the Agent must proceed immediately to the ChatGPT Classic connection and OAuth instead of reopening the router, reinstalling Caddy or repeating DNS work. Optional Multi-Main, Goal/Rescue and extra capability setup comes after core MCP acceptance.

Both packaged setup Skills, their OpenAI interface prompts, the capability manifest, README, current setup guides and installer output carry this contract. A dedicated static release gate verifies that none of the required steps or tools disappears in a future edit.

DevSpace checkpoint, handoff and recovery can keep a project moving beyond one conversation's usable context. This is durable continuity, not a literal increase or bypass of OpenAI model context windows, token allowances, account usage or rate limits.

The workflow follows current official OpenAI developer guidance for a public `/mcp` endpoint, Developer mode connection, OAuth, discovered tools/metadata and end-to-end tool testing:

- https://developers.openai.com/plugins/deploy/connect-chatgpt
- https://developers.openai.com/plugins/build/auth
- https://developers.openai.com/plugins/build/app-quickstart
