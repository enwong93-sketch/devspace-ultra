# DevSpace Ultra v0.5.12 — transactional updater busy-state hotfix

This hotfix includes the complete v0.5.11 bounded Classic Main relay-retention repair and fixes one deployment blocker found during production rollout.

The Windows transactional updater queries the authenticated Stable Gateway status endpoint before replacing a live package. That status request is itself admitted by the Gateway before its snapshot is generated, so the old updater always observed at least one active HTTP request—its own probe—and incorrectly reported `active-work` even when `totalNonStreamActiveRequests` was zero.

The updater now subtracts exactly that one control request from the admission count. Every additional in-flight HTTP request and every real non-stream MCP/tool request still defers the update, so active work remains protected without requiring `-Force`.

All v0.5.11 safeguards remain included: recurring progress reports do not mount relay Apps, one-time progress binding is explicit, progress and Goal relay frames are bounded and retired, crowded-page ownership recovery stays bounded, the visible narration card and durable history remain intact, and loopback proxy trust is scoped safely.
