# DevSpace Ultra v0.5.17 — same-turn capability recovery

This hotfix removes the visible `devspace_instance_binding_required` regression introduced by v0.5.14-v0.5.16. After one successful exact-page `devspace_progress_report`, ordinary read, write, edit, command and capability tools may run repeatedly during the same ChatGPT turn without asking the user to bind the page again.

The recovery is not a durable session fallback. Every call must match the original MCP session and exact request trace, remain inside the bounded lease, and re-verify the globally unique local Classic page plus opaque progress claim. Another computer, Connector App, conversation, request trace or ambiguous page cannot reuse it.

The complete `verify:ultra` suite and the focused multi-server isolation, progress narration and server-instance gates pass. Existing Main windows and conversations do not need to be recreated.
